Free PDF Tools in Your Browser

FileDrawer provides simple PDF and image utilities for everyday tasks. You can merge PDF documents, extract pages, convert images to PDF, and add text watermarks.

How does FileDrawer work?

File processing is performed by JavaScript running in your browser. Your selected files are processed locally instead of being uploaded to a FileDrawer server.

Why use FileDrawer?

  • No account required for the tools.
  • Simple interface designed for phones and computers.
  • Useful PDF operations in one place.
  • Local browser processing for the supported tools.

About FileDrawer

FileDrawer is a simple collection of browser-based PDF and image utilities designed to make common document tasks easier.

Our goal

The goal of FileDrawer is to provide useful document tools with a straightforward interface and without requiring users to create an account just to perform basic operations.

Available tools

  • Merge PDF documents
  • Split and extract PDF pages
  • Convert JPG and PNG images to PDF
  • Add text watermarks to PDF files

Local processing

The current tools use JavaScript and PDF libraries inside the browser. This means supported file operations are performed locally on the user's device.
